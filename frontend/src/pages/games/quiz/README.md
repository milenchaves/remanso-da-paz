# Quiz de Conhecimentos

Este diretório contém os arquivos do jogo Quiz de Conhecimentos.

## Arquivos

- `QuizLevels.js` - Perguntas organizadas por nível (Fácil, Médio, Difícil)
- `QuizGame.jsx` - Componente principal do jogo
- `QuizGame.css` - Estilos do jogo

## Importante

Se estes arquivos sumirem, verifique:
1. Se estão commitados no Git: `git status`
2. Se não foram deletados acidentalmente
3. Se há algum processo de build limpando arquivos

## Restaurar arquivos

Se os arquivos sumirem, eles podem ser restaurados através do histórico do Git ou recriados seguindo a estrutura dos outros jogos.
